**Método (importante):** NO se usa el editor de Canva para crear los artes — se abandonó porque la API de Canva no deja diseñar bien (no crea elementos nuevos, no cambia fondos, edición "a ciegas" por coordenadas). En su lugar: **HTML/CSS renderizado localmente con Playwright/Chromium** → PNG final 1080×1350. Control total, gratis, reproducible. Cada plantilla es un script `build_*.py` parametrizado; solo se cambia el dict CONTENT.

**5 plantillas aprobadas por JR (2026-07-16):**
- `build_portada.py` — portada/hook de apertura (título + palabra clave subrayada en amarillo)
- `build_contenido.py` — título + párrafo + viñetas opcionales + cierre
- `build_contenido_imagen.py` — igual + ventana de imagen arriba
- `build_contenido_frase.py` — cita/frase destacada con atribución
- `build_cierre.py` — CTA "¡Ponte en Contacto!" + logo + barra de contacto clara
- `build_flyer.py` — FLYER de detalles para promoción/publicidad (talleres/cursos/diplomados): badge de urgencia opcional + título del evento + filas de datos (Fecha/Modalidad/Horario/Cupos/Inversión...) + CTA. Tarjeta blanca sobre crema, un solo acento amarillo. Para piezas marcadas `Publicidad`/`Producto`/`Event` en Notion.
- `build_infografia.py` — grilla de tarjetas de colores (ícono emoji + etiqueta corta); para conjuntos de conceptos paralelos
- `build_pasos.py` — diagrama de pasos numerados conectados por una línea; para secuencias/progresiones
- `build_comparacion.py` — dos columnas (ej. "mito vs realidad", "esperar vs acompañar", "antes vs después")
- `build_dato.py` — número grande o gráfico de dona con UN porcentaje; guardarraíl: exige fuente real, avisa fuerte si falta
- `build_promo.py` — **SUB-SISTEMA DE PROMOS/PUBLICIDAD** (talleres/cursos/diplomados), distinto a los artes diarios. Ver regla abajo. Funciones: `render_cover` (portada-flyer), `render_foto`, `render_incluye`, `render_temario`, `render_cierre`. Cada una recibe `(content, theme, out_path)`. Paletas en dicts `THEME_*` (ej. `THEME_ALIMENTACION`, cálida tomate/miel/verde). Orquestador de ejemplo: `armar_taller_alimentacion.py`.
