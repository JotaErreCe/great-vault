# Crisol TCG — búsqueda inicial de proveedores para Guatemala

## Objetivo

Identificar rutas de abastecimiento para Crisol TCG en Guatemala: distribuidores oficiales/mayoristas para producto sellado y accesorios, y tiendas locales como benchmark/contacto puente.

## Hallazgos iniciales

### Devir Américas — prioridad alta

Fuente: `https://deviramericas.com/nuevos-clientes/` y `https://deviramericas.com/ots/`.

- Devir Américas declara ser distribuidor oficial para Latinoamérica de, entre otros: **Konami, Pokémon, Wizards of the Coast, Ultra PRO, Ultimate Guard, Chessex, WizKids, Paizo**.
- Vende solo a tiendas establecidas físicas o en línea, no a jugadores/personas individuales.
- Requisitos relevantes:
  - tienda física o tienda online establecida con carrito;
  - alta fiscal del país / NIT o equivalente;
  - nociones de importación: materiales vienen de USA; envío, impuestos y desaduanaje a cargo del cliente;
  - compra mínima mensual de **USD 600** para mantener cuenta activa;
  - tienda online: tarjeta Visa/Mastercard/Amex/Discover;
  - tiendas virtuales: según página, solo juegos de mesa y accesorios con 25% off MSRP; confirmar si aplica igual para TCG.
- Para Yu-Gi-Oh OTS, Devir indica que el producto Konami debe adquirirse directa y exclusivamente con Devir antes de iniciar proceso OTS.

### Pokémon TCG

- Pokémon Support tiene artículo sobre distribuidores mayoristas, pero el fetch directo devolvió 403. Search confirmó la existencia del recurso.
- Devir Américas lista **Pokémon** como marca oficial para LatAm.
- Búsquedas públicas sugieren presencia de equipo TCG Latin America de The Pokémon Company International, pero no se verificó canal de compra directa para Guatemala.
- Tiendas locales detectadas para benchmark: PokeCardsGT, PokéWorldGT, Poke Monstruo.

### Magic: The Gathering

- Wizards WPN tiene página oficial de distribuidores (`https://wpn.wizards.com/en/distributors`), aunque el contenido extraído fue limitado.
- Devir Américas lista **Wizards of the Coast** como marca oficial para LatAm y tiene página de juego organizado WPN.
- Ruta práctica inicial: abrir cuenta Devir y consultar requisitos WPN/abastecimiento para Guatemala.

### Yu-Gi-Oh!

- Devir Américas tiene página específica OTS y exige compra directa/exclusiva con Devir para proceso OTS.
- Requisitos OTS detectados:
  - tienda física con señalización exterior permanente;
  - amplia selección de Yu-Gi-Oh!;
  - mínimo 1 torneo mensual;
  - espacio para al menos 16 jugadores;
  - exhibición de producto sellado;
  - facturas de distribuidor autorizado.

### One Piece / Bandai Card Games

Fuente: `https://en.onepiece-cardgame.com/topics/getting-started/`.

- Bandai indica que retailers deben contactar distribuidores oficiales de su área.
- Distribuidores oficiales listados en la página internacional incluyen: **GTS Distribution, Alliance Game Distributors, Universal, Coqui Hobby**, entre otros por regiones.
- La página pide contratar solo distribuidores ubicados/enfocados en el área correspondiente.
- No se confirmó distribuidor específico para Guatemala; candidatos a contactar: GTS/Alliance/Universal/Coqui Hobby y preguntar cobertura para Guatemala.
- TCG Factory aparece como distribuidor mayorista de One Piece y publicación LinkedIn dice distribuidor oficial Bandai Card Games, pero parece España/Europa; confirmar si exporta a Guatemala.

### Accesorios

- Devir Américas lista **Ultra PRO** y **Ultimate Guard** como marcas oficiales para LatAm.
- Ultra PRO tiene página de distribuidores y soporte dice que no ofrece wholesale/direct retailer account propio, sino vía partners/distribuidores.
- Dragon Shield tiene portal retailer directo (`dragonshielddirect.com`); posible ruta para accesorios, pendiente confirmar cobertura Guatemala/importación.

### Tiendas / benchmarks locales Guatemala

No tratarlas automáticamente como proveedores mayoristas oficiales; útiles como benchmark, competencia, potencial seller estratégico o contacto puente.

- PokeCardsGT — Pokémon TCG Guatemala, cartas 100% originales, preventas/envíos.
- El Bicho Super Store — productos TCG, accesorios, torneos, envíos a Guatemala.
- PokéWorldGT — Pokémon, accesorios, producto TCG.
- Poke Monstruo Guatemala — Pokémon TCG.
- Smiley Games — juegos de mesa Guatemala; posible canal geek/retail.
- Juegos Metta — juegos/juguetes Guatemala; posible canal retail.
- Magic Board Games Guatemala — juegos de mesa; posible benchmark.
- Pacifiko — vende productos Wizards/Bandai; probablemente retail/marketplace, útil para precios y disponibilidad, no necesariamente proveedor TCG.

## Otros candidatos detectados — 2026-08-13

Tras ampliar búsqueda, sí hay más rutas además de Devir, aunque con distintos niveles de certeza/cobertura para Guatemala:

### Coqui Hobby Distribution

- Aparece en página oficial de One Piece/Bandai como distribuidor oficial por área.
- ICv2 registró históricamente expansión de Coqui para Wizards of the Coast en México y Brasil.
- Ruta útil: preguntar si cubre Centroamérica/Guatemala para Bandai, Wizards u otros TCG.

### GTS Distribution / Alliance Game Distributors / Universal Distribution

- Listados por One Piece Card Game como distribuidores oficiales.
- Probablemente más fuertes para EE.UU./Canadá, pero vale preguntar si aceptan retailers/importadores de Guatemala o si remiten al distribuidor regional.

### TCG Factory

- Mayorista español de TCG; aparece con One Piece y publicación LinkedIn indica distribuidor oficial Bandai Card Games.
- Posible para importación paralela/Europa, no confirmado para Guatemala.

### Explosion Distributions

- División mayorista/distribución en México/USA, puente entre proveedores internacionales y retailers locales.
- Candidato para consulta B2B regional, pendiente verificar catálogo TCG real y exportación Guatemala.

### Devir México

- Separado de Devir Américas; se presenta como distribuidor principal de entretenimiento en México.
- Puede servir como ruta alterna o referencia, aunque para Guatemala probablemente remita a Devir Américas.

### Brasil/Chile — baja prioridad para Guatemala

Detectados varios distribuidores B2B TCG (Geek Culture Distribution, Cartinha, Super TCG, Geek Distribuidora, Ferret Games), pero parecen enfocados en mercados nacionales Brasil/Chile. Útiles solo si exportan o si se busca arbitraje/importación no oficial.

## Recomendación operativa

1. Prioridad 1: abrir investigación/contacto con **Devir Américas** para cuenta B2B de Crisol.
2. Preparar paquete comercial mínimo: nombre comercial, NIT/figura jurídica, URL, concepto de tienda online, categorías, volumen inicial estimado, dirección de importación, si habrá tienda física/eventos.
3. Preguntas clave a Devir:
   - ¿Cubre Guatemala directamente?
   - ¿Puede abastecer Pokémon, MTG, Yu-Gi-Oh, Ultra PRO y Ultimate Guard para tienda online?
   - ¿Restricción real para TCG si Crisol empieza solo online?
   - MOQ por línea, margen/descuento, lead time, forma de pago, incoterms/envío, release dates/preorders.
4. Prioridad 2: Bandai/One Piece — consultar GTS, Alliance, Universal y Coqui Hobby sobre cobertura Guatemala.
5. Prioridad 3: accesorios — Devir para Ultra PRO/Ultimate Guard y Dragon Shield Direct como ruta alternativa.
